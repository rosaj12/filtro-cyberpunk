
# Filtro Cyberpunk — Pixels em Tempo Real

## Descrição

Aplicação web para captura e processamento de
imagens da webcam em tempo real.

O projeto utiliza operações matemáticas sobre
os canais RGBA para produzir um filtro Cyberpunk.

## Tecnologias

- HTML5
- CSS3
- JavaScript ES6+
- Canvas API
- MediaDevices API

## Arquitetura

O software utiliza módulos JavaScript independentes.

- App: coordenação da aplicação.
- Camera: gerenciamento da webcam.
- Renderer: processamento e renderização dos frames.
- Cyberpunk: transformação matemática dos pixels.
- PixelMath: operações matemáticas auxiliares.

## Execução

Executar o projeto por meio de um servidor local,
como a extensão Live Server do VS Code.

## Objetivo acadêmico

Demonstrar o processamento matemático de pixels
RGBA utilizando inteligência artificial como
auxílio ao desenvolvimento (AIDD).
